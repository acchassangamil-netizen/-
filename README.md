# توكيل كوكاكولا أبو حمده

تطبيق ثابت بدون خادم أو Node.js. يُنشر على GitHub Pages أو أي استضافة HTTPS ثابتة.
افتحه مرة واحدة بالإنترنت وانتظر رسالة «جاهز للعمل بدون إنترنت»، ثم افتحه من نفس العنوان والمتصفح أو ثبّته كتطبيق من قائمة Chrome.

البيانات محفوظة في IndexedDB لهذا المتصفح وهذا العنوان، ولا تُرسل إلى GitHub. مسح بيانات الموقع أو تغيير الجهاز أو المتصفح أو عنوان الموقع لا ينقل البيانات. استخدم تصدير JSON والاسترجاع للنقل، واحفظ نسخًا خارج المتصفح بانتظام.

تبدأ النسخة بأسماء مناديب تجريبية وأرصدة وأهداف صفر؛ يمكن نقل بيانات نسخة SQLite السابقة بتصدير JSON منها واسترجاعه هنا. لم يتم استيراد بيانات Google Sheets.

## نشر GitHub Pages
ضع هذه الملفات في جذر المستودع. من Settings → Pages اختر Deploy from a branch ثم الفرع main والمجلد root.
كل تغيير لاحق يرفع إلى الفرع المختار يُنشر عبر Pages. لا ترفع ملفات قواعد البيانات أو النسخ الاحتياطية أو بيانات العمل إلى المستودع.

## التحديث
عند تعديل أي ملف، غيّر CACHE في sw.js إلى رقم إصدار جديد، مثال abuhamda-shell-v2. هذا يضمن تنزيل ملفات الإصدار كاملة. يظهر زر «تحديث البرنامج متاح» بعد اكتمال التنزيل؛ احفظ النموذج المفتوح ثم اضغطه. بيانات IndexedDB مستقلة عن ملفات التحديث.

## الحسابات
الرصيد = أول المدة + المبيعات - المرتجعات - كل التحصيلات.
نسبة التحصيل = تحصيل المبيعات في الشهر / الهدف، ولا تشمل تحصيل المديونية.
فواتير Q مستبعدة. الأهداف عامة لكل الشهور. حدود المديونية كما في النسخة المحلية السابقة.

يمكن فتح index.html مباشرة في Chrome للمعاينة، لكن العمل عبر رابط HTTPS هو المسار المدعوم للتثبيت والأوفلاين والتحديثات وثبات عنوان البيانات.

## الإدخال اليومي والمراجعة والشهور
شاشة الإدخال اليومي تقبل صفًا لكل مندوب في التاريخ المحدد، أو لصق خلايا Excel بالترتيب المعروض على الشاشة. يلزم معاينة قبل الاعتماد. يمنع تسجيل اليوم لنفس المندوب إذا وُجدت حركات سارية، والتراجع عن دفعة يلغي حركاتها مع سجل للمراجعة. ليس هذا استيرادًا تلقائيًا لأي تنسيق من الأمين؛ يلزم تهيئة تقريره بعد توفير عينة.
يمكن تعديل الحركة من كشف الحساب مع سبب إلزامي وحفظ القيم السابقة. إعدادات الأهداف والسياسات خاصة بالشهر المحدد. رصيد أول المدة هو أصل الحساب ولا يُضاف مجددًا عند الترحيل؛ يُمنع تغييره طالما توجد شهور مقفولة. إقفال الشهر يثبت أرصدة نهاية الشهر ويمنع تعديل حركاته، ويفتح الشهر التالي بنفس الإعدادات إن لم يكن موجودًا. إعادة الفتح تتطلب سببًا، ويجب فتح الشهور المقفولة الأحدث أولًا.
خطة التحصيل تقديرية حسب حد المديونية القادم مع افتراض عدم وجود حركات جديدة. تذكير النسخة الخارجية يسجل وقت طلب التنزيل فقط؛ على المستخدم التأكد من حفظ الملف.

## مستندات الأمين والتصميم
الحركة الفردية الجديدة تتطلب رقم مستند الأمين الأصلي. يمكن إدخال السلسلة أو الفرع واسم العميل. يمنع التكرار عبر جميع المناديب حسب سنة الحركة ونوع المستند والسلسلة، مع توحيد الأرقام العربية واللاتينية والمسافات وحالة الحروف عند الفحص فقط؛ يبقى الرقم الأصلي ظاهرًا كما أُدخل. تحصيل المبيعات والمديونية يشتركان في نطاق أرقام سندات القبض. البيانات التجميعية السابقة لا تُحوّل إلى أرقام فواتير وهمية. عند إضافة مستند في يوم له تجميع من نفس النوع والمندوب يلزم تأكيد أنه غير محتسب في التجميع لتجنب المضاعفة.
مركز المستندات يدعم البحث والفلترة والفترات والملغى وتفاصيل المستند وتصدير نتائج البحث. خط Cairo مضمّن محليًا بصيغة WOFF2 تحت رخصة SIL OFL المحفوظة في fonts/OFL-Cairo.txt، ولا يحتاج البرنامج خدمة خطوط خارجية.

## نقدية المناديب والتوريد
استيراد كشف 13102 يحتفظ بجميع أسطر المصدر ويجمع بنود رقم السند الواحد داخل حساب النقدية نفسه وتاريخه. وفق توجيه المستخدم: المدين تحصيل من العملاء، والدائن توريد للخزينة الرئيسية. لا يمثل حساب النقدية مديونية المبيعات. التحصيل وحده يخفض مديونية المندوب مرة واحدة؛ التوريد يؤثر على النقدية فقط. لا يتم جمع المدين والدائن باعتبارهما تحصيلًا.
التحصيل المستورد غير المصنف بين مديونية قديمة ومبيعات الشهر يظهر تحت التصنيف، ويُستبعد من نسبة الهدف حتى مراجعته. سند القبض قد يحتوي بنودًا لعدة حسابات مناديب؛ منع التكرار للتحصيل يستعمل حساب النقدية أيضًا. أصل سند القبض ورقم سند الأمين محفوظان منفصلين.
الأرصدة السالبة تُعرض كما في المصدر وتحتاج مراجعة، ولا تُسوّى بقيم افتتاحية مفترضة. كشف النقدية واجهة للكشوف المستوردة؛ الحركات اليدوية خارجها لا تنشئ قيدًا نقديًا تلقائيًا. يمكن تصنيف التحصيل المستورد وإضافة بيان دون تعديل قيمه أو أرقامه؛ يلزم كشف مصدر مصحح لتعديلها. إلغاء التحصيل يلغي قيده النقدي المرتبط ويظهر فرقًا عن إجمالي المصدر.
