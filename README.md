# توكيل كوكاكولا أبو حمده

تطبيق ثابت بدون خادم أو Node.js. يُنشر على GitHub Pages أو أي استضافة HTTPS ثابتة.
افتحه مرة واحدة بالإنترنت وانتظر رسالة «جاهز للعمل بدون إنترنت»، ثم افتحه من نفس العنوان والمتصفح أو ثبّته كتطبيق من قائمة Chrome.

البيانات محفوظة في IndexedDB لهذا المتصفح وهذا العنوان، ولا تُرسل إلى GitHub. مسح بيانات الموقع أو تغيير الجهاز أو المتصفح أو عنوان الموقع لا ينقل البيانات. استخدم تصدير JSON والاسترجاع للنقل، واحفظ نسخًا خارج المتصفح بانتظام.

تبدأ النسخة بأسماء مناديب تجريبية وأرصدة وأهداف صفر؛ يمكن نقل بيانات نسخة SQLite السابقة بتصدير JSON منها واسترجاعه هنا. لم يتم استيراد بيانات Google Sheets.

## نشر GitHub Pages
ضع هذه الملفات في جذر المستودع. من Settings → Pages اختر Deploy from a branch ثم الفرع main والمجلد root.
كل تغيير لاحق يرفع إلى الفرع المختار يُنشر عبر Pages. لا ترفع ملفات قواعد البيانات أو النسخ الاحتياطية أو بيانات العمل إلى المستودع.

## التحديث
عند تعديل أي ملف، غيّر CACHE في sw.js إلى رقم إصدار جديد، مثال abuhamda-shell-v2. هذا يضمن تنزيل ملفات الإصدار كاملة. يظهر زر «تحديث البرنامج متاح» بعد اكتمال التنزيل؛ احفظ النموذج المفتوح ثم اضغطه. بيانات IndexedDB مستقلة عن ملفات التحديث.

## الحسابات
الرصيد = أول المدة + المبيعات - المرتجعات - كل التحصيلات.
نسبة التحصيل = تحصيل المبيعات في الشهر / الهدف، ولا تشمل تحصيل المديونية.
فواتير Q مستبعدة. الأهداف عامة لكل الشهور. حدود المديونية كما في النسخة المحلية السابقة.

يمكن فتح index.html مباشرة في Chrome للمعاينة، لكن العمل عبر رابط HTTPS هو المسار المدعوم للتثبيت والأوفلاين والتحديثات وثبات عنوان البيانات.
